# CS-157A-Summer-Project

To start:
Run: pip install -r requirements.txt

Then navigate towards the src file and run:
python .\app.py

This will initiate the local server

Afters copy the path that leads to the signup.html to a chrome web browser (Firefox will not work since there are configuration that are needed)
and then run thefile and it should be good to go

**Note:
you will need to create a .gitignore with a .env file and put your information for your DB.
